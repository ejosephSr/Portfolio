## Updating the site

1. Pull the latest changes: `git pull`
2. Edit `index.html` in VS Code and save.
3. Preview by opening `index.html` in a browser.
4. Commit and push:
   ```bash
   git add -A
   git commit -m "Describe the change"
   git push
   ```
5. GitHub Pages updates in 1–2 minutes. Refresh with **Ctrl+F5**.

> **Note:** GitHub Pages is case-sensitive. Image paths must match the folder name exactly (`Images/V2/`, capital V).
